# PokeWave

TeamSpeak 3 原生客户端 Poke 测试插件，使用官方 Client Plugin SDK 的 `requestClientPoke`。

当前版本不设置速率和次数的业务上限：速率必须是正的有限数；总次数必须是大于 0 且能放入 `uint64` 的有限整数。任务可随时 `/pokewave stop`，断线和插件卸载会自动停止。
